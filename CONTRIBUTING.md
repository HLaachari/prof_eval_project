# Contribuer à Classia

Merci de contribuer à Classia. Les corrections ciblées, améliorations d’accessibilité et propositions liées au suivi pédagogique sont bienvenues.

## Installation

1. Forkez puis clonez le dépôt.
2. Exécutez `npm install`.
3. Copiez `.env.example` vers `.env` et configurez une base de données de développement.
4. Lancez `npm test`, puis `npm run check` avant de proposer une modification.

## Proposer une modification

- Créez une branche courte et descriptive.
- Limitez chaque pull request à un sujet cohérent.
- Décrivez le problème, la solution et la méthode de vérification.
- Ajoutez ou adaptez les tests lorsque le comportement change.
- Ne joignez jamais de fichier `.env`, d’export de base de données, de liste de classe ou de donnée personnelle d’élève.

## Données de démonstration

Les exemples et captures doivent utiliser uniquement des personnes fictives et des identifiants manifestement factices. Aucun nom, code Massar, date de naissance, note, présence ou observation issu d’un établissement réel ne doit être commité.

## Signaler un problème de sécurité

N’ouvrez pas de ticket public contenant un secret ou une donnée personnelle. Contactez directement le mainteneur du dépôt avec une description minimale permettant de reproduire le problème.
